# WhatsApp Chat Analyzer  

This repository contains a **WhatsApp Chat Analyzer**, a tool that helps users extract insights from exported WhatsApp chat data. It provides statistical and visual analysis of conversations, identifying trends, message frequencies, and user interactions.  

### 🔗 **Live Demo**  
Try the WhatsApp Chat Analyzer online:  
👉 [WhatsApp Chat Analyzer](https://whatsappchatanalyser-sv.streamlit.app/)  

## 📌 Features  

✅ **User Activity Analysis** – Identify the most active participants in the chat.  
✅ **Message Frequency** – Analyze the number of messages sent over time.  
✅ **Word Cloud** – Generate a word cloud of the most frequently used words.  
✅ **Media & Link Sharing** – Track the number of media files and links shared.  
✅ **Sentiment Analysis** *(Upcoming Feature!)* – Analyze the sentiment of messages.  

## 🚀 Installation  

To use this tool locally, follow these steps:  

1️⃣ Clone the repository:  
   ```bash
   git clone https://github.com/Velprakash0611/Whatsapp_chat_analyser.git
   ```
2️⃣ Navigate to the project directory:  
   ```bash
   cd Whatsapp_chat_analyser
   ```
3️⃣ Install the required dependencies:  
   ```bash
   pip install -r requirements.txt
   ```
4️⃣ Run the application:  
   ```bash
   python main.py
   ```

## 📤 How to Export WhatsApp Chat  

1. Open WhatsApp on your phone.  
2. Navigate to the chat you want to analyze.  
3. Tap on the three dots (menu) → **More** → **Export Chat**.  
4. Choose **Without Media** for a cleaner analysis.  
5. Save the exported `.txt` file and place it in the project folder.  

## 🎯 Usage  

1. Run the script and upload your WhatsApp chat file.  
2. The analyzer will process the chat data and generate insights.  
3. Visualizations and statistics will be displayed for better understanding.
